The framework

The framework assesses a concrete MDP formulation of observational clinical data before any reinforcement-learning agent is trained. It answers two questions separately, because an MDP can be a sound description of practice while the data still cannot support evaluating a different policy.

Question A: is MDP modelling appropriate?

  • Level A: clinical problem suitability (expert metadata plus data proxies)
  • Level B: formulation validity: state and reward sufficiency, decision interval, action alignment, stationarity, transition estimability

Question B: does the dataset support offline RL?

  • Level C: temporal data quality
  • Level D: overlap, coverage, importance-sampling reliability, behaviour-history dependence; unmeasured confounding is always reported as not assessable

Level E (deployment readiness) is qualitative and answered only by clinical metadata. Each criterion reports a value, an uncertainty interval, its assumptions, a status and a recommended next step. The strongest positive status is no concern detected; the framework never states that data are safe, valid or causally identified.

Methods and metrics per level

Shared core: cross-fitted information gain plus GCM test

Most of Levels A, B and D use one estimator. It asks whether extra information Z improves the prediction of a target Y when X is already known. The gain is the out-of-sample improvement in log-likelihood (Gaussian for continuous targets, log-loss for actions) when Z is added. Its unit is nats per transition. It uses 5-fold cross-fitting grouped by patient, and a bootstrap over trajectories gives the CI. For Gaussian residuals the gain estimates the conditional mutual information I(Y; Z | X). Where marked, the GCM conditional-independence test (Shah & Peters 2020), clustered by trajectory, runs alongside it.

Equivalence rule with relevance threshold δ = 0.01 nats:

  • No concern detected when the upper CI bound is below δ, even if the test rejects.
  • Concern when the lower bound is at least δ and the test rejects.
  • Otherwise Inconclusive.

Level E (deployment) has five metadata questions: definable constraints, interpretability requirements, a fallback policy, safeguards for unusual patients, clinician oversight. All thresholds except Pareto-k̂ = 0.7 (Vehtari et al.) are conventions documented in the code and reported with sensitivity analyses. Within one criterion the worst sub-result counts; there is no aggregate score.

Main sources: information gain and approximate information states (Subramanian et al. 2022); GCM test (Shah & Peters 2020); positivity (Petersen et al. 2012; Raghu et al. 2018); ESS and PSIS (Kish; Vehtari et al.); temporal data quality (Kahn et al. 2016; Agniel et al. 2018).

Among 60 cases the framework flagged, the recommended revision (adding history) reduced the value-estimation error by 71%, while random revisions increased it by 23%. For small violations (c = 0.2) the revision brought no improvement, which supports using an effect-size threshold, not significance alone.

Overlap and coverage

The support-violation rate tracks the true violation rate well (ρ = 0.82) but underestimates it by 0.14 on average, because a smooth behaviour model cannot represent hard restrictions. Effective sample size anticipates off-policy evaluation error best, but only moderately (ρ = −0.44); no pre-training diagnostic predicts that error precisely.

PK/PD anaesthesia simulator

All state representations were flagged, including the full compartment state. Further checks showed this is correct: drug kinetics depend on unrecorded patient characteristics, so past observations identify the patient. A coarser decision interval (6 instead of 2 minutes) raised history dependence of the BIS-only state from 0.07 to 0.6 nats.

Temporal data defects

Each defect moved its own indicator and left the others alone. Recording actions one step late dropped the action-effect gain from 0.43 to 0.00; random missingness left the informative-missingness test at chance level, as it should.

Case study: eICU sepsis

Overlap looks excellent until history is included. Given heart rate and blood pressure alone, the norepinephrine dose looks almost random (entropy 0.97, no support violations). The previous dose predicts the next one very strongly (0.95 nats). With that history included, entropy drops to 0.30 and importance sampling becomes unreliable (Pareto-k̂ 1.34). The framework now runs this history-aware check automatically.

The near-zero dose effect is consistent with closed-loop titration (the dose is adjusted to keep blood pressure stable) or with timing misalignment; these data cannot separate the two. Finer steps (30 minutes) made importance sampling worse; coarser steps (120 minutes) bundled more decisions into one step. The cardiac-arrest cohort has no treatment variable, so the framework rules out MDP modelling from it, matching the earlier interdisciplinary project.

Statistical findings only, not clinical conclusions. Patient data stay outside the repository; only aggregate reports are stored.

Problems found and fixed

  • Spurious history dependence from state columns that are exact copies of earlier values (lagged states, static covariates, noise-free compartments). Such columns are now excluded automatically.
  • Over-optimistic overlap when the state omits what drives treatment decisions. Fixed by the history-aware behaviour model.
  • Unobserved actions were invisible to overlap diagnostics. The action space can now be declared.
  • Model-class dependence: a linear model falsely flags a reward that is nonlinear in the next state. Reporting both linear and flexible models is recommended.

Limitations

  • Diagnostics only see dependence on recorded variables; a latent factor that leaves no trace is undetectable.
  • No conditional-independence test has power against every alternative, so non-rejection is never proof of the Markov property.
  • Gains are relative to the base model's fit and must be compared across formulations together with the model fit.
  • Only the Pareto-k̂ threshold (0.7) and α = 0.05 have an external basis; all other thresholds are conventions.
